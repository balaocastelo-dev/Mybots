# MCP Tech Support — Assistência Técnica Balão

Agregador inspirado nas categorias MCP:
🎧 Suporte & Gestão · 🧠 Conhecimento & Memória · 🗄️ Bancos de Dados · 🧬 Medicina/Diagnóstico · 🔧 Ferramentas Dev

## Quando Invocar

- Ao criar ou atualizar uma **Ordem de Serviço (OS)**
- Quando usuário pedir **diagnóstico automático** de hardware
- Ao montar **orçamento de serviço técnico
- Quando precisar consultar **base de conhecimento** de defeitos comuns
- Ao gerar **avisos automáticos** de cliente via WhatsApp

## Workflow OS

1. **Entrada OS:** Dados cliente, equipamento, defeito relatado
2. **Triagem IA:** Consulta base de conhecimento → 3 diagnósticos mais prováveis (com % de confiança)
3. **Orçamento:** Calcula peças + mão de obra + PIX -15%
4. **Aprovação:** Envia orçamento via WhatsApp
5. **Andamento:** Atualiza status automaticamente
6. **Pronto:** Avisa cliente + dispara feedback
