# Bling (opcional)

Isto não é o sistema da loja. O financeiro do Balão continua no `balao-sistema`. Este complemento fala com `https://mcp.bling.com.br/mcp`, OAuth no item `bling.oauth` do cofre.

Criar ou alterar pedido, estoque, contato ou lançamento pede confirmação. Sem o ok, só consulta.
